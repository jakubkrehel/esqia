## How It Works

<Point icon="cursor" />Click into any markdown on the page and edit it.

<Point icon="slash" />Press `/` on an empty line for headings, code blocks and your own components.

<Point icon="text" />Select text for **bold**, *italic*, `code`, [links](https://github.com/jakubkrehel/esqia) or your own marks, like a <em className="font-libre-baskerville">serif</em> font.

<Point icon="drag" />Drag any block to move it, including demos.

<Point icon="diff" />Blocks you didn't touch are written back byte for byte, so your diffs stay small.

<br />

Try it on this page. Press the square in the bottom left and click any paragraph.

<br />

Type `-` and a space to start a list.

- Enter adds an item.
- Enter on an empty item ends the list.

Type `1.` and a space for a numbered one.

1. Backspace at the start of the first item turns it back into text.
2. <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>↑</Kbd> moves the item under the caret up.

<br />

Type three backticks and a space for a code block.

```tsx
<Esqia />
```

<br />

Images and videos stay as they are. Drag them like any other block.
