## How It Works

<Point icon="cursor" />Click into any markdown on the page and edit it.

<Point icon="slash" />Press `/` on to insert headings, code blocks and line breaks.

<Source />

<Point icon="text" />Select text to apply **bold**, *italic*, `code`, [links](https://github.com/jakubkrehel/esqia) or your own styles.

<Point icon="drag" />Drag any block to move it, including demos.

<Diff />

<Point icon="components" />Supports your already existing MDX components.

<Point icon="media" />Images and videos work just like any other blocks.
