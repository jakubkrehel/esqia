## How It Works

<Point icon="cursor" />Click into any markdown on the page and edit it.

<Point icon="slash" />Press `/` on an empty line for headings, code blocks and your own components.

<Point icon="text" />Select text for **bold**, *italic*, `code`, [links](https://github.com/jakubkrehel/esqia) or your own marks, like a <em className="font-libre-baskerville">serif</em> font.

<Point icon="drag" />Drag any block to move it, including demos.

<Point icon="diff" />Blocks you didn't touch are written back byte for byte, so your diffs stay small.

## Keyboard Shortcuts

- <Kbd>⌘</Kbd> <Kbd>⌥</Kbd> <Kbd>E</Kbd> switches between reading and editing.
- <Kbd>/</Kbd> at the start of an empty line opens a menu with text, headings, a code block, a line break and your snippets. Type to filter, use the arrows or <Kbd>Tab</Kbd> to move and <Kbd>Enter</Kbd> to choose.
- `-`, `*` or `+` and a space starts a bulleted list. `1.` or `1)` and a space starts a numbered one.
- <Kbd>Enter</Kbd> in a list adds an item. On an empty item it ends the list.
- <Kbd>⌫</Kbd> at the start of the first item turns it back into text.
- <Kbd>⇧</Kbd> <Kbd>Enter</Kbd> in a paragraph splits it with a line break between the halves. Typing `<br />` on a line adds one too.
- <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>↑</Kbd> and <Kbd>⌘</Kbd> <Kbd>⇧</Kbd> <Kbd>↓</Kbd> move the block or list item under the caret.
- <Kbd>⌘</Kbd> <Kbd>Z</Kbd> inside the editor undoes typing.
