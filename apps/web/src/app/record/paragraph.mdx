## Building an animated sign in dialog

Instead of changing the background color of the tab component in the active state, we add an absolutely positioned container with `inset-0` and we animate it using [shared layout animations](https://interfaces.dev/magazine/issues/how-i-use-shared-layout-animations).

/

This way the tab indicator animates between the different states. The way this works under the hood is fairly complex, but there's [an entire issue](https://interfaces.dev/magazine/issues/how-i-use-shared-layout-animations) about the technique with some great reading materials that explain it in detail.
